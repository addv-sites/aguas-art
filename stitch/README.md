# Agua Artesanal — One Page

Propuesta estática basada en la referencia visual generada.

## Archivos

- `index.html` — sitio completo, sin backend.
- `DESIGN.md` — especificación visual para OpenCode.
- `assets/design-reference.png` — referencia.
- `assets/logo-transparent.png` — logo proporcionado por el cliente, procesado para uso digital.
- `assets/logo-original-enhanced.jpg` — versión mejorada del logo original.
- `assets/*.png` — recortes visuales derivados de la referencia.

## Ejecutar

Abrir `index.html` directamente en navegador o publicarlo en GitHub Pages.

## Importante

Las fotografías de productos usadas en esta maqueta fueron recortadas de la propuesta visual generada. Antes de producción deben reemplazarse por fotografías reales del catálogo de Agua Artesanal.

También deben validarse contra el catálogo todos los sabores, presentaciones, claims, precios, cobertura y condiciones de entrega.
